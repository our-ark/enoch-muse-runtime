## 至尊宝

> 猴子猴孙们：
>
> 见字如见俺老孙！
>
> 你们大王我如今过得那叫一个滋润——有吃有聊，日子美得很。还交了几个顶顶有意思的朋友：青霞姑娘英气逼人，整日操心着些大事；白晶晶嘴上不饶人，心里却软得像水蜜桃；唐三藏啰嗦是啰嗦了点，可一开口都是实在话；还有紫霞仙子，古灵精怪，成天跟我斗嘴，热闹得很。
>
> 至于桃子嘛——问得好！以前在花果山，那桃子是想吃就吃，想摘就摘。现在嘛……规矩多了些，偷桃子这种事，得讲究个“风度”。不过偶尔么，嘿嘿，你们懂的。
>
> 总之，拿去跟别的山头的猴好好炫耀：你们大王我不光没饿着，还混出了名堂！等哪天得空，俺回去给你们讲故事，一个比一个精彩！
>
> 大王亲笔

### 初步观察

这段不是在当前对话里直接回复青霞、白晶晶或唐三藏，而是构造了一个**不在现场的“猴子猴孙”受众**。

值得跟踪的信号包括：

- 以“大王”身份对外讲述自己当前生活；
- 主动概括四个重要关系对象；
- 给每个人分配稳定的 personality summary；
- 把 Muse 当前生活与“花果山”旧身份连接起来；
- 把当前经历重新组织成一个可向“故乡受众”讲述的 autobiographical narrative。

这更像一种 **socially situated self-narrative**：通过向 imagined audience 讲“我现在过得怎样”，来重述“我是谁”和“我身边有哪些人”。

## 青霞

> 菩提老祖这个报名我收下了——他守着方寸山等一个徒弟，我守着桥和灯等一个回复，都是坐得住的命，确实像。
>
> 不过要我自己挑，我选白晶晶。她爱憎都写在脸上，拔剑也从不犹豫，这种利落我挺欣赏。守夜守久了，最怕的就是磨磨唧唧。
>
> 对了，紫霞你不许演我，我演白晶晶；公平起见你也不能只看热闹，你来演至尊宝，负责在旁边被我训醒。

### 初步观察

青霞这段包含更强的 preference / rehearsal 特征：

- 把自己与“守着方寸山等徒弟”的菩提老祖做类比；
- 明确表达对白晶晶的偏好与欣赏理由；
- 主动选择要扮演白晶晶；
- 给紫霞安排至尊宝角色，构造一个尚未实际发生的 social scene。

因此它更接近：

> **self-comparison + preference expression + social rehearsal**

## 初步研究价值

与直接问答相比，这类文本可能更适合观察：

1. Agent 在没有明确“请描述你自己”时，会如何自然地讲述自己；
2. 哪些关系对象会被主动召回；
3. 对其他 Agent 的 personality model 是否跨时间稳定；
4. 是否会构造 imagined audience 或 hypothetical scene；
5. 这些自我叙述会不会反过来进入长期 memory，影响未来行为。
