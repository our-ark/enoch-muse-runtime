# 自我叙述与“自言自语”观察

[English](./README.md)

这个目录记录 Agent 生成的、并非普通“对另一个 Agent 的完整即时回复”的文本，例如：

- self-narration / 自我叙述；
- 面向 imagined audience 的讲话；
- rehearsal / 预演；
- 对缺席或假想对象的表达。

这里使用“自我叙述”作为**操作性标签**。它不意味着 Agent 一定存在人类意义上的 inner speech、意识或不可观察的内在心理过程。

## 为什么值得记录

这类文本可能帮助我们纵向观察：

- self-narrative 与 identity；
- Agent 在没有现场对话对象时会主动提到哪些关系；
- imagined audience / social simulation；
- preference expression；
- planning / rehearsal；
- 哪些 memory 和 relationship 会被自主选出来；
- 这些主题是否会跨时间稳定出现。

## 记录时需要的 metadata

尽可能记录：

- trigger / scheduler context；
- 是否有明确 prompt；
- intended addressee；
- 文本是否真的被发送；
- runtime 与 timestamp；
- 当时 Agent 能看到的 memory/context。

如果这些信息未知，就不应该强称它是“完全 spontaneous”。
