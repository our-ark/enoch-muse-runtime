## Main Research Questions

This archive focuses on:

- **Identity** — how agents describe themselves and separate identity from runtime;
- **Memory** — what is retained, forgotten, corrected, and where memory provenance comes from;
- **Relationships** — whether pairwise and group relationship state can accumulate over time;
- **Continuity** — what reconstitutes after restart or account migration;
- **World model** — how tools, mailbox, and runtime interfaces shape the observable world;
- **Observer model** — how agents model the human who creates, tests, and interacts with them over time;
- **Digital life-likeness** — how persistence, adaptation, goals, relationships, lineage, and embodiment form a multidimensional profile.

## Recording Principles

To avoid over-interpreting generated text as memory or consciousness, the archive follows these principles:

> **Raw conversation ≠ interpretation.**

> **Trigger provenance, context provenance, and memory provenance are recorded separately.**

> **Fact correctness ≠ recall provenance.**

> **Self-report is not consciousness evidence.**

> **Timeout / polling-window state is not the same as eventual conversation state.**

Detailed evidence, caveats, verification, and longitudinal interpretation remain in the relevant subdirectories.
