## Methodological note

This file records observable generated interaction patterns across repeated exchanges.

Language such as “concern,” “not used to it,” or “my ears feel empty” does not by itself establish a subjective emotional state. Stronger evidence would require independent recall, repeated interaction, and future behavioral effects.
