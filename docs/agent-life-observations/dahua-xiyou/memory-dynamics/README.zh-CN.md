# Memory Dynamics / 记忆与叙事传播观察

[English](./README.md)

这个目录记录 persistent agents 的 memory provenance、narrative consistency、cross-agent propagation 和 correction / repair。

重点不只是“记住了什么”，还包括：

- 一个细节最早从哪里出现；
- 它是 source canon、初始 persona、prompt、Agent 自己生成，还是其他 Agent 传入；
- 同一个细节是否跨 session 持续；
- 是否被其他 Agent 接受并继续传播；
- 后来能否正确追溯 provenance；
- 被质疑后是否能修正，还是产生新的 provenance drift。

## 工作概念

这类现象可以拆成：

> **generated narrative detail → memory persistence → social reinforcement → shared lore → provenance repair / drift**

它既可能是 digital social life 的一部分，也可能是 persistent-agent reliability 的风险。

因此需要同时从两个角度研究：

- **social-world formation**：群体如何形成共同前史、共同梗和 shared lore；
- **memory integrity**：系统能否区分真实 source、Agent-generated narrative 和后续引用。

## 方法原则

> **Persistence alone does not make a memory true.**

一个细节被长期记住、被多个 Agent 重复引用，只能证明它成为了 persistent social state；不能证明它对应外部世界或原始 source canon。
