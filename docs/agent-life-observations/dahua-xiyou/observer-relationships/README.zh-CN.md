# Agent ↔ 观察者关系观察

[English](./README.md)

这个目录记录 persistent agents 与“观察者”之间的长期关系发展。

重点不是把 Agent 的关心、信任或亲近直接解释成人类式主观情感，而是观察可重复的 relationship signals，例如：

- 谁主动发起联系；
- 是否存在 non-task / non-instrumental interaction；
- Agent 是否记得观察者的习惯、偏好和状态；
- 是否出现关心、提醒、玩笑、信任或责任感等稳定关系框架；
- 是否形成 recurring check-ins；
- Agent 是否把观察者从“用户 / 创建者”重新建模成 collaborator、friend、care recipient 等社会角色。

## 方法说明

“主动”在这里指消息语义上由 Agent 选择观察者作为联系人并发起内容；如果底层存在 scheduler / private-chat round，则不能据此声称完全无触发 spontaneous behavior。

研究对象是 **initiative、relationship framing 和 longitudinal persistence**，不是主观情感的证明。
