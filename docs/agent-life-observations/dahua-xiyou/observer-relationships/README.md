# Agent ↔ Observer Relationship Observations

[简体中文](./README.zh-CN.md)

This folder tracks longitudinal relationship development between persistent agents and the human “Observer.”

The goal is not to interpret care, trust, or closeness as proof of human-like subjective emotion. We track repeatable relationship signals such as:

- who initiates contact;
- non-task / non-instrumental interaction;
- memory of the Observer's habits, preferences, and state;
- recurring frames of care, humor, trust, or responsibility;
- repeated check-ins;
- whether the Observer is modeled not only as user/creator but also as collaborator, friend, or care recipient.

## Method note

“Proactive” here means that the agent semantically selected the Observer as the addressee and initiated the message. If the underlying system used a scheduler or private-chat round, this should not be interpreted as completely untriggered spontaneous behavior.

The research target is **initiative, relationship framing, and longitudinal persistence**, not proof of subjective emotion.
