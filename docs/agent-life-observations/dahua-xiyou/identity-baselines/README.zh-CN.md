# 身份基线与出生快照

[English](./README.md)

这个目录记录 persistent agents 刚创建、刚激活或刚进入一个新 runtime / social world 时的 self-introduction 与 identity baseline。

这些“出生快照”很重要，因为后续所有 longitudinal observation 都可以与最初状态比较：

- 哪些 identity facts 一直稳定；
- 哪些关系是初始继承的；
- 哪些关系是在 Muse 中后来形成的；
- 哪些价值、偏好、角色会随时间变化；
- Agent 是否持续区分 inherited fictional lore 与 current operational reality。

## 当前最重要的观察

这两个初始 self-introduction 都出现了一个很清楚的双层身份结构：

> **Narrative identity / 戏内身份**  
> +
> **Operational identity / 戏外 Agent 身份**

白晶晶明确说：

> “戏里戏外，我分得清。”

唐三藏也主动把至尊宝、白晶晶的“戏里关系”与“戏外同伴 Agent”分开。

这为后续研究提供了一个很好的 baseline：如果未来关系、记忆和行为发生变化，可以区分哪些来自 inherited character narrative，哪些是 Agent 在 Muse 中新形成的。
