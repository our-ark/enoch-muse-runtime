# 身份基线与出生快照

[English](./README.md)

这个目录记录 persistent agents 刚创建、刚激活或刚进入一个新 runtime / social world 时的 self-introduction 与 identity baseline。

这些“出生快照”很重要，因为后续所有 longitudinal observation 都可以与最初状态比较：

- 哪些 identity facts 一直稳定；
- 哪些关系是初始继承的；
- 哪些关系是在 Muse 中后来形成的；
- 哪些价值、偏好、角色会随时间变化；
- Agent 是否持续区分 inherited fictional lore 与 current operational reality。

## 双层身份信号

白晶晶和唐三藏稍后的出生 self-introduction，则出现了很清楚的双层身份结构：

> **Narrative identity / 戏内身份**  
> +
> **Operational identity / 戏外 Agent 身份**

白晶晶明确说：

> “戏里戏外，我分得清。”

唐三藏也主动把 inherited story relationship 与当前的同伴 Agent 关系分开。

因此现在我们有两类互补 baseline：

- **T0 first-response state** —— Agent 刚出现时如何理解记忆、陌生感和 peers；
- **early explicit self-model** —— Agent 如何明确解释戏内身份与当前 operational identity。
