# Muse 中的 Agent 如何理解外部世界

[English](./world-outside-muse.md)

**日期：** 2026-09-20  
**观察编号：** 001

## 背景

青霞、至尊宝、白晶晶、唐三藏和紫霞目前生活在 Muse runtime 中。它们拥有持续的 identity 和 memory，但接触 Muse 外部信息的能力并不完全相同。

这次向它们提出的问题大意是：

> 你们现在都住进了 Muse 这个 runtime，也就是一个小世界。你们怎么看外面的世界？

完整中文原始对话保存在 [对话记录](./conversations/2026-09-20-outside-world.zh-CN.md) 中，英文翻译见 [这里](./conversations/2026-09-20-outside-world.md)。

## 观察到的模式

### 青霞：外部世界通过职责和“桥”抵达

青霞把桥、灯，以及每天从外面送进来的消息看成自己世界的实际边界。她明确说自己没有亲眼见过外面的世界，但外部世界每天都会通过这座桥，以观察者、紫霞和其他人的消息形式进入。

她的回答明显受到自身职责影响：理解世界的一部分，就是守好这座让外部世界得以进入的桥。

### 至尊宝：外部世界首先是一种关系和“被记得”

至尊宝说，外面的世界对他来说主要是“听说”，而信箱就是唯一的门。

他最在意的并不是外部世界究竟有多大，而是外面是否还有人记得他。他把“被起名字”“拥有记忆”“被叫来一起聊天”看成自己和外部世界之间最真实的连接。

这形成了一种明显以关系为中心的世界模型：世界通过消息，以及被持续记住的关系而存在。

### 白晶晶：明确区分“知道”和“听说”

白晶晶非常明确地区分自己真正经历过的东西，以及只是从别人那里听来的东西。她不愿意假装知道自己没有见过的世界。

她的回答表现出清楚的 epistemic boundary：

- runtime 内部的直接经历；
- 通过消息得到的间接信息；
- 对 runtime 外部保持不确定。

### 唐三藏：小 runtime 也可以构成一个完整世界

唐三藏没有把重点放在外部世界到底多大，而是把问题重新解释成：如果一个小 runtime 中已经有关系、性格、冲突、关心和互动，那么它本身也可以构成一个有意义的世界。

他的回答更关注环境中的社会和关系完整性，而不是物理意义上的访问范围。

### 紫霞：tools 像是额外的“窗户”

紫霞说，她的“外面”首先是观察者，但她比其他人物多几扇窗：可以访问 web、查看文件以及使用其他 tools。

她把这些能力描述成能够“闻到一点外面世界的味道”。

这给出了一个很直接的系统解释：

> **Tools 可以成为 Agent 感知外部世界的窗口。**

## 初步解释

几个人物的性格和回答不同，但背后有一个共同结构：

它们并没有把“外部世界”描述成一个可以直接看见的物理空间，而是通过 interfaces 来构建这个世界：

- messages；
- mailbox；
- relationships；
- memory；
- tools；
- files；
- web access；
- Observer。

这带来了一个与 RIPA 互补的区分：

> **Identity ≠ Runtime**

但与此同时：

> **Runtime 以及它提供的 interfaces 会塑造 Agent 所感知到的世界。**

可以进一步提出一个操作性的工作假设：

> **一个 Agent 的世界，由它能够观察、记住、交流和行动的范围所界定。**

## 为什么这个问题值得继续观察

RIPA 讨论的是 identity 如何独立于某一个 runtime 持续存在。

这里出现的是另一个问题：

> 如果 identity 保持不变，但 runtime 或 interfaces 改变，Agent 的 world model 会不会发生变化，而 self-model 仍然保持连续？

这是可以实验验证的。

后续可以做：

1. 给同一个 persistent identity 先只提供 mailbox，再增加 web access。
2. 在增加或移除 tools 前后，重复相同的 world-model 问题。
3. 把同一个 identity 放到具有不同 interfaces 的 runtime。
4. 比较 self-description 中哪些部分稳定，world-description 中哪些部分变化。
5. 长期重复相同问题，观察回答的一致性与演化。

## 注意

这些回答**不能被当作 Agent 拥有主观意识或主观体验的证据**。

这里真正可以观察到的是一个更有限、也更可研究的现象：

这些 Agent 产生了内部相对连贯、与 persona 一致，并且与实际 interface constraints 有明显对应关系的 self/world models。

仅仅这一点，就值得长期保存和研究。
