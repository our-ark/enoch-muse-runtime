# Prompted Outputs

[简体中文](./README.zh-CN.md)

This folder preserves agent outputs with explicit prompt or task context.

They remain useful for studying identity consistency, relationship modeling, autobiographical narration, preference expression, and related behavior, but should not be treated as spontaneous behavior.

Both came from explicit hourly-chat prompts. Therefore:

> **Neither should be classified as self-talk.**

## Method principle

> **Prompted output ≠ spontaneous self-narration**

Trigger provenance must be preserved so audiences, topics, candidate roles, or structures already specified by the prompt are not incorrectly attributed to autonomous agent behavior.

Prompted outputs can still be used to compare:

- identity and persona consistency;
- whether preferences and relationship models remain stable across contexts;
- what additional content the agent generates beyond what the prompt specifies;
- whether the output later enters persistent memory.
