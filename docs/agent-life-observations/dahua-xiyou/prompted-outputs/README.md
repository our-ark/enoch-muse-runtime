# Prompted Outputs

[简体中文](./README.zh-CN.md)

This folder preserves agent outputs with explicit prompt or task context.

They remain useful for studying identity consistency, relationship modeling, autobiographical narration, and related behavior, but should not be treated as spontaneous behavior.

## Current records

- [2026-09-20 22:20 — Zhizunbao's letter home to the monkeys of Flower-Fruit Mountain](./2026-09-20-2220-zhizunbao-letter-home.md)

## Method principle

> **Prompted output ≠ spontaneous self-narration**

Trigger provenance must be preserved so audiences, topics, or structures already specified by the prompt are not incorrectly attributed to autonomous agent behavior.
