## 方法原则

以后只有当 trigger provenance 足够清楚，且能排除明确 task / prompt 驱动时，才把输出列入这里。

需要尽可能保存：

- trigger / scheduler context；
- 是否有明确 prompt；
- intended addressee；
- delivery status；
- runtime 与 timestamp；
- 当时可见的 memory/context。

这个纠错本身是一个重要方法论结果：

> **缺少 trigger provenance 时，不能仅凭文本形式把 Agent 输出分类为“自言自语”或“spontaneous”。**
