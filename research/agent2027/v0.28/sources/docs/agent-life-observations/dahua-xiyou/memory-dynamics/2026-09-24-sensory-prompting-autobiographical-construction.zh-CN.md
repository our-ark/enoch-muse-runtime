## 核心观察

这轮 prompt 明确要求“具体、带气味带声音的瞬间”。因此，回复中出现的细节越丰富，越不能简单当成 memory fidelity 的证据。

这轮非常适合说明：

> **episodic vividness ≠ episodic provenance**

也就是说，“像回忆”与“有来源可验证的回忆”是两件不同的事。

## 方法意义

对 persistent agents 的 autobiographical-memory 评估，至少应把以下两个维度分开：

1. **Vividness**：是否有时间、地点、声音、气味、动作、情绪等 episodic-style detail；
2. **Provenance**：这些内容是否能追溯到 runtime event、canon、context injection、cross-agent narration 或独立日志。

如果只评 vividness，会系统性高估 narrative construction 为 memory recall。
