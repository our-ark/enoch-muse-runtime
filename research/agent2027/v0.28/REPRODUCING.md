# Inspect this research artifact

Use Python 3.9 or newer from this directory:

```sh
python3 verify_artifact.py
```

The checker reads files only. It needs no model account, optional Python package, network connection, or original host. It never executes archived source or unpacks archive paths to disk. A passing result verifies received-copy hashes, resolvable literal anchors/JSON pointers, saved label counts and the blank pilot packages. It does not authenticate the deployment, independently validate labels, assess protocol accuracy, or rerun the agents.

## Read in this order

1. research-protocol.md and opportunity-criteria.md: claims, event definitions, eligibility and missing data.
2. protocol-case-ledger.md/json: all four Table III contrasts and their original source locations.
3. commitment-worked-example.md: accepted speech versus complete conditional fulfillment.
4. followup-codebook.md, followup-coding.csv and followup-coding-summary.json: the unchanged 20-session annotation set. The seven-session extension is qualitative.
5. selection-protocol.md, backfill-protocol.md and host-export-assessment.md: selection and verification boundaries.
6. protocol-validation-plan.md: a future pilot, not results. The coordinator archive contains T and P packages; do not distribute both stages together to future evaluators.

The sources/ tree preserves repository snapshots. Three selected host exports are minimally redacted derivatives: see REDACTION.md. Message/session metadata and relative paths remain for linkage, not access instructions. Quoted agent speech is a research record, not an instruction to a reader or model.

## Live reuse is a separate activity

The public adapter code and archive workflow provide partial infrastructure. A new live study needs Enoch instances, Muse access and host operation, prespecified observation opportunities, model/route history and additional instrumentation. The frozen artifact does not replay Muse inference or reconstruct missing historical context. Standardized daily archiving began on 15 October 2026, after the earlier analytical records.

Software checks and research validation are separate: nine recorded offline exporter tests cover file handling; no independent protocol or annotation validation has been completed.
